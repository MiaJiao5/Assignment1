# Assignment 1 — Why Are We Here?
我觉得不管是设计师还是艺术家，代码对于这类人群来说他其实就像是一只笔，这支笔能够帮你画出不同的设想并让他们落地。那么，怎么样使用这支笔以及使用的方法就变得极为重要，尽管现在Ai能帮你生成任何东西，但是这些逻辑始终是基于代码的逻辑，如果对于代码完全没有理解的话，就像是让一位体育老师作为将军带军代打仗一样让人觉得疑惑。他对于战术和军队一点都不了解的话，我相信他无法长久指挥军队并带领军队一直取得胜利。

首先，对我来说刚刚学习这些代码并了解AI和计算机的时候，正如 Dylan Beattie 在其演讲 《The Art of Code》 中所提到的，“code就像是一片雪花一样，你每次都像是在开盲盒。运行这些代码前你对于最后的样式和生成结果是毫无预设的。这让我想起我在大学第一学期在第一次使用C4D时第一次用参数来随机生成一些具有艺术感的形状，每次调整一次，这些有机排列的单元体竟然神奇的以一种和人类全然不同的逻辑组合在一起，这些组合体有时候竟然还有一种特殊的美感！这也从某种程度上激起了我对于机械语言的好奇心。但是这个时候这些参数对我来说就像是在开潘多拉的魔盒一样，我对于结果几乎没有预设，我不知道开出来的东西是好的或者坏的？所以对我来说他几乎是不可控的。所以在这之后的很长一段时间我对代码的不了解导致我对代码有一些恐惧。

这两年由于AI的发展，编程也变得友好了不少。所以，我也开始试着用AI创作游戏，视频，网页。虽然我能够通过大模型生成各式各样的东西，但是目前仍然存在着两个问题.第一个问题是AI可以基本帮我解决前端的视觉上的东西，但一但涉及上线，部署这种硬件框架，我就会不知道如何操作了。 第二个问题是在需要精细调整的时候，尽管我能用自然语言（LLM）和AI直接沟通我需要解决的问题，但这样操作很费时间。如果我对编程有一定了解的话，我就能更快速准确的解决这些问题。

我在写这个文章的时候已经上了两节创意编程的课了，目前我已经成功通过vscode把本地的应用文件上传到github仓库，然后通过cloudfalre发布公共网站🙂，并且对于本地和云端联合部署网站和python代码都有了一些新的理解。另外，我感觉对于代码也没有那么害怕了！✌

最后我觉得学习编程并不是为了去和代码编译器较劲，而是为了在 AI 时代守住你作为一个创作者的判断力、独特性和不可替代的审美直觉。同时帮助我更好的地使用AI进行创作，我想这就是我为什么在这儿的原因。

对于设计师或艺术家而言，代码从来不是枯燥的技术苦差事，而是一只能够将抽象设想绘制并落地的画笔。既然这支笔如此重要，那么如何掌握并使用它便成了关键。尽管如今的 AI 能够根据简单的英文指令生成各种内容，但其底层逻辑依然植根于代码。如果对代码完全缺乏理解，盲目让 AI 代劳，就像让一位体育老师去充当运筹帷幄的将军——由于对战术和军队一无所知，他将无法长久地指挥队伍并赢得胜利。

回想起自己最初接触编程和计算机时，正应了 Dylan Beattie (2019) 在其演讲《The Art of Code》中所提到的那样，“代码就像是一片雪花一样，你每次都像是在开盲盒。”在运行代码之前，你对最终的视觉呈现往往毫无预设。这让我想起大学第一学期初次使用 C4D 时，通过参数随机生成艺术化形状的经历。每次调整参数，那些有机排列的单元体便以一种完全不同于人类思维的逻辑组合在一起，往往会碰撞出一种奇特的美感。

然而，这种未知在当时也伴随着代价。对当时的初学者而言，这些参数更像是潘多拉的魔盒：由于缺乏对结果的预设，我无从判断生成的东西是好是坏，一切都处于失控状态。这种“由于不了解而产生的失控感”，让我在很长一段时间里对代码怀有一丝敬畏与恐惧。

转折发生在近两年。随着 AI 技术的发展，编程的门槛变得友好了许多，我也开始尝试利用 AI 创作游戏、视频和网页。但在实际操作中，痛点依然显现：第一，AI 虽然能高效搞定前端的视觉呈现，但一旦涉及上线、部署等底层的硬件与网络框架，我便会陷入盲区；第二，在需要进行精细化调整时，单纯通过自然语言（LLM）与 AI 反复沟通不仅费时，而且隔靴搔痒。如果我对编程本身有一定的认知，就能以极高的效率精准定位并解决问题。

经过前两节创意编程课的实践，这种状况有了实质性的改变。我已经成功通过 VS Code 将本地应用文件上传到 GitHub 仓库，并通过 Cloudflare 顺利发布了公共网站。在这个过程中，我对本地与云端的联合部署以及 Python 代码的运行逻辑有了全新的理解，曾经对代码的恐惧也在一次次敲击键盘和成功部署中烟消云散。

归根结底，在 AI 时代学习编程并不是为了去和编译器死磕，而是为了守住作为一个创作者的判断力、独特性和不可替代的审美直觉。代码不再是高不可攀的结界，而是驾驭 AI、实现个性化表达的最佳工具。我想，这就是我们为什么会在这里的原因。
